# `.jcode/docs/` — Documentación del arnés agnóstico

> Esta carpeta contiene la documentación complementaria del arnés
> v100-clean. Todos los archivos aquí son **agnósticos al proyecto**:
> aplican a cualquier stack o dominio.

## Índice

| Doc | Propósito |
|---|---|
| `VISION-STRATEGY.md` | Estrategia de visión (cuándo usar `@playwright/cli`, `cdp-browser-mcp`, `@playwright/test`) |
| `CONTEXT-CACHING.md` | Cache de snapshots y fetches entre turnos del agente |

## Convenciones

- Documentos en esta carpeta son del **arnés**, no del proyecto.
- Documentos específicos del proyecto (manuales de uso, decisiones
  de arquitectura, runbooks) van en `docs/` en la **raíz del repo**.
